# KaaS Platform Synthetic Demo Dataset

This package contains a large-scale synthetic dataset for demonstrating the Knowledge as a Service (KaaS) platform.

## Core Scale
- Users: 50,000
- Courses: 50,000
- Total generated records across all CSV files: 411,000

## Files
- enterprises.csv
- skills.csv
- users.csv
- courses.csv
- enrollments.csv
- assessments.csv
- certificates.csv
- gamification.csv
- social_posts.csv
- forum_threads.csv
- training_batches.csv
- ai_tutor_sessions.csv
- dataset_schema_and_relationships.json

## Use Cases Covered
- LMS and LXP course catalog
- Learner profiles and personalization
- Enterprise training management
- AI tutor sessions
- Gamified learning and leaderboards
- LLM-generated assessments
- Credential and certificate verification
- Social learning feed
- Forums and peer learning
- Skill graph and competency mapping

## Notes
This is synthetic data for PoC, demo, analytics, UI testing, and backend integration. It does not contain real user data.
